# 参赛文案与信息汇总（初稿）

> 版本：2026-10-31。文案依据 AX7021 实测与已归档硬件实现数据整理，可用于技术报告和报名字段。

## 作品名称

**Zynq 加速的轻量级目标检测系统**

## 作品简介

本项目在 Zynq-7000 上实现 PL 图像预处理与 ARM/Linux 目标检测协同运行。PL 使用 Q0.6 定点运算将 RGB888 图像从 640×480 缩放至 300×300，双 store AXI VDMA 通过 HP0 将图像写入 DDR，ARM/Linux 上的 Float32 SSD-MobileNetV1 完成目标检测。Q0.6 行缓存映射使用 2 个 RAMB36E1；双 store 系统完成 XC7Z020 100 MHz routed 实现，并通过多帧和 DDR 背压仿真。在 AX7021 固定帧实测中，板上 RGB 输出与 golden 逐字节一致，检测返回 16 个目标且运行无错误；本次 DMA helper 用时约 4.014 ms，ORT wall time 约 2.505 s，从输入就绪到检测结果约 2.578 s。

## 简短版

基于 Zynq-7000 的 PL-PS 协同边缘目标检测系统。PL 执行 Q0.6 RGB888 定点缩放，双 store AXI VDMA 传输帧数据，ARM/Linux 运行 Float32 SSD-MobileNetV1。系统已完成 XC7Z020 实现、RTL/VDMA 仿真和 AX7021 固定帧检测；板上 RGB 与参考结果逐字节一致。

## 三个关键词

**Zynq-7000；PL-PS 协同；边缘目标检测**

## 项目亮点

1. **异构计算链路：** PL 像素处理、AXI-Stream、双 store VDMA/DDR 传输和 ARM/Linux 神经网络推理组成一条清晰的数据流。
2. **片上存储优化：** Q0.6 行缓存采用双端口 RAMB36E1 结构，以 2 个 RAMB36E1 完成缩放行缓存，相较四缓冲映射减少一半 BRAM36 用量；routed WNS 为 +0.384 ns。
3. **系统资源效率：** XC7Z020 双 store 实现使用 4,649 LUT、5,186 个寄存器、9 个 BRAM tile 和 6 个 DSP；100 MHz routed 实现 setup/hold 失败端点数为 0。
4. **实板结果可追溯：** AX7021 输出 RGB 与 Q0.6 参考文件逐字节一致，同次运行完成 16 个目标检测；原始帧、日志、检测记录和哈希均已归档。
