# 项目创新点与技术优势

## 项目概述

项目面向 Zynq-7000 边缘视觉平台，将 PL 定点图像预处理、双 store AXI VDMA 帧传输、DDR 数据交接和 ARM/Linux 神经网络检测连成一条可测量、可复核的系统链路：

**RGB888 → PL Q0.6 缩放 → 双 store AXI VDMA/HP0 → DDR → ARM/Linux Float32 SSD-MobileNetV1 → 检测结果**

项目的技术贡献集中在异构数据流设计、片上存储结构优化、帧交接实现与实板结果的可追溯验证。

## 创新点与优势

### 1. 面向 Zynq 的 PL-PS 异构检测数据流

将图像缩放交给 PL 流水线，将神经网络推理交给 ARM/Linux：PL 接收 RGB888 像素流，完成 Q0.6 定点缩放后，通过双 store AXI VDMA 和 HP0 写入 DDR，ARM/Linux 再读取 300×300 RGB 图像完成 Float32 检测。模块边界和数据格式明确，便于分阶段验证，也方便在同一套结构上继续接入摄像头或更换推理模型。

### 2. Q0.6 行缓存的 BRAM 结构优化

缩放器采用双端口 RAMB36E1 组织行缓存，完成图像缩放只使用 2 个 RAMB36E1。对比四缓冲映射实现，BRAM36 用量降低 50%，额外占用 25 个 LUT；独立 100 MHz 实现报告的 routed WNS 为 +0.384 ns。该结构把有限片上存储留给更高效的像素缓存，同时保留与整数 golden reference 的精确逐字节比较能力。

### 3. 双 store VDMA 帧交接与背压适应

通过双 store AXI VDMA 建立 PL 图像流与 DDR 帧存之间的交接路径。系统仿真覆盖多帧不同内容、store 回绕、DDR 读写背压和复位后重放，输出帧与 golden reference 匹配。XC7Z020 100 MHz routed 实现使用 4,649 LUT、5,186 个寄存器、9 个 BRAM tile 和 6 个 DSP，WNS/WHS 为 +0.183/+0.053 ns，setup/hold 失败端点数为 0。

### 4. 板上逐字节核验的端到端实测

在 AX7021 上完成固定输入图像的 PL 缩放、VDMA 传输和 ARM/Linux 检测。300×300 输出为 270,000 字节，与 Q0.6 golden 逐字节一致；检测返回 16 个结果，runner 错误数为 0。实验同时记录 DMA helper、ORT 推理和输入就绪至后处理完成的时间，并保存原始 RGB、JSONL、日志、检测图和 SHA-256，形成从硬件输出到算法结果的可追溯证据链。

本次固定帧实测记录：DMA helper 4.014 ms；ORT wall time 2.505 s；输入文件就绪至后处理结果 2.578 s。

## 可用于报告的表述

> 本项目面向 Zynq-7000 边缘视觉平台，构建了由 PL 定点缩放、双 store AXI VDMA/DDR 帧交接和 ARM/Linux Float32 目标检测组成的 PL-PS 协同系统。Q0.6 图像缩放采用双端口 RAMB36E1 行缓存，在保持 golden reference 精确比对的同时，将 BRAM36 使用量相较四缓冲映射减少 50%。双 store 数据通路完成 XC7Z020 100 MHz routed 实现，并通过多帧、DDR 背压和复位重放仿真。在 AX7021 固定图像实测中，板上 RGB 输出与 Q0.6 参考结果逐字节一致，检测器返回 16 个结果且运行无错误，相关原始数据和哈希均可复核。
