## 项目成果摘要

PL Q0.6 RGB888 缩放、双 store VDMA 与 ARM/Linux Float32 检测已在 AX7021 上完成一次固定输入图像实验。板上输出与 golden 逐字节一致，检测返回 16 个结果。详细架构、实现资源和计时定义见交接包的 `02_实验记录/` 与 `02_C1_实板结果/`。
