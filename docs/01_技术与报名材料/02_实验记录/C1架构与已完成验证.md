# C1 架构与已完成验证

项目创新点、报告段落和证据映射见 ../06_任务与交付表单/项目创新点与技术优势.md。

## 系统结构

AX7021（Zynq-7000）上的图像检测数据流为：

**RGB888 输入 → PL Q0.6 定点缩放 → 双 store AXI VDMA → HP0/DDR → ARM/Linux Float32 SSD-MobileNetV1。**

PL 侧把 640×480 RGB 图像缩放至 300×300；双 store VDMA 在 DDR 帧区完成数据交接；ARM/Linux 侧将输出 RGB 送入 ONNX Runtime 检测。

## 实现亮点

- **PL-PS 协同分工清晰：** 像素级缩放放在 PL，检测推理运行在 ARM/Linux，数据经标准 AXI-Stream、VDMA 和 DDR 接口传递。
- **定点精度可复核：** Q0.6 RTL 对应整数 golden reference，板上输出可逐字节核验。
- **片上存储更精简：** Q0.6 行缓存实现使用 2 个 RAMB36E1；对比早期四缓冲映射实现，BRAM36 用量减半，额外占用 25 个 LUT。独立 100 MHz 实现报告中 routed WNS 为 +0.384 ns。
- **双 store 数据通路经过多情形仿真：** Q0.6 RTL 行为级与 RAMB36E1 primitive 仿真各通过 29 个用例。真实 AXI VDMA 仿真覆盖不同帧内容、双 store 回绕、DDR 背压和复位重放；逐帧输出与 golden 匹配。
- **系统资源明确：** XC7Z020 双 store 实现报告为 4,649 LUT、5,186 个寄存器、9 个 BRAM tile、6 个 DSP；100 MHz routed WNS/WHS 为 +0.183/+0.053 ns，0 个 setup/hold failing endpoint。

## AX7021 固定帧实测

已在 AX7021 上完成一张固定图像的完整缩放、DMA 传输和 ARM/Linux 检测：

- 300×300 RGB 输出为 270,000 字节，与 Q0.6 golden 逐字节一致。
- 检测器返回 16 个结果，runner 错误数为 0。
- DMA helper 用时约 4.014 ms；ORT wall time 约 2.505 s；从输入就绪到后处理结果约 2.578 s。
- 原始 RGB、JSONL、日志、检测可视化及哈希记录位于 `../02_C1_实板结果/`。

本次板测使用固定文件图像。上述实测数字为单帧结果；RTL/Vivado 数字则分别以仿真和实现报告为依据。
