# 项目说明与已完成工作

## 项目目标

在 AX7021（Zynq-7000）上实现边缘目标检测：PL 负责图像缩放，ARM/Linux 执行神经网络推理，通过 AXI VDMA 和 DDR 连接两侧数据流。

## 系统数据流

**640×480 RGB888 输入 → PL Q0.6 定点缩放至 300×300 → 双 store AXI VDMA → HP0/DDR → ARM/Linux Float32 SSD-MobileNetV1 → 目标检测结果。**

PL 以流式方式处理像素；双 store 缓冲完成帧交接；ARM/Linux 将输出 RGB 送入 ONNX Runtime。该结构把预处理和推理分别放到适合的计算单元，数据格式保持 RGB888，方便与检测器输入及 golden reference 对照。

## 技术亮点

- **PL-PS 协同：** 将定点缩放、AXI-Stream、双 store VDMA/DDR 数据交接和 ARM/Linux 推理贯通。
- **BRAM 行缓存优化：** Q0.6 缩放使用 2 个 RAMB36E1；对比四缓冲映射，BRAM36 用量减少一半，额外占用 25 个 LUT。独立 100 MHz 实现的 routed WNS 为 +0.384 ns。
- **可复核的定点计算：** RTL 与整数参考模型逐像素比较；行为级和 RAMB36E1 primitive 仿真均通过 29 个用例。
- **双 store 系统实现：** XC7Z020 routed 结果使用 4,649 LUT、5,186 个寄存器、9 个 BRAM tile 和 6 个 DSP；WNS/WHS 为 +0.183/+0.053 ns，setup/hold 失败端点均为 0。
- **实板图像一致性：** AX7021 输出 RGB 与 Q0.6 golden 逐字节相同，便于从输入、硬件输出到检测结果逐项复核。

## 已完成的板上实验

AX7021 完成一张固定图像的 PL 缩放、DMA 传输和 ARM/Linux 检测。输出为 270,000 字节 RGB；检测器返回 16 个结果，runner 错误数为 0。本次 DMA helper 用时约 4.014 ms，ORT wall time 约 2.505 s，输入文件就绪至后处理结果约 2.578 s。

原始 RGB、检测 JSONL、日志、可视化和 manifest 位于 `02_C1_实板结果/`。现有 18 秒讲解片可用于介绍这次板测；任务表安排了现场演示视频、报告、源码仓库和提交材料的后续制作。
